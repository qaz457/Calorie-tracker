# Calorie Tracker (КП RUDZ)

Консольное приложение на C++ для ведения дневника питания и расчёта суточной нормы калорий, белков, жиров и углеводов (КБЖУ).

## Возможности

- Регистрация и авторизация пользователей
- Просмотр КБЖУ-отчёта за текущий день
- Добавление приёмов пищи
- Просмотр архива питания
- Добавление новых продуктов в общую базу
- Закрытие дня, сортировка списка продуктов
- Редактирование профиля

## Системные требования

- Windows 7/10/11 (64-bit)
- Visual C++ Redistributable
- Процессор Intel/AMD x86-64, 1 ГГц и выше
- 512 МБ ОЗУ и выше
- 10 МБ свободного места на диске

## Сборка

Открыть `src/KP.sln` в Visual Studio (2019 или новее, поддержка C++17) и собрать конфигурацию `Release | x64`.

## Структура репозитория

```
src/    — исходный код и файлы проекта Visual Studio
docs/   — техническая документация, пояснительная записка, презентация
```

## Данные

При первом запуске программа автоматически создаёт рядом с исполняемым файлом:

- `users.txt` — база пользователей
- `products.txt` — общая база продуктов питания
- `<логин>_diary.txt` — дневник питания пользователя
- `<логин>_history.txt` — история питания по дням

Эти файлы не хранятся в репозитории (см. `.gitignore`).

## Управление

Отмена любого действия — клавиша `ESC`.
